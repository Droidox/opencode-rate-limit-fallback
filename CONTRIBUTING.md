## Contributing

Thanks for helping improve this project.

This fork builds on azumag's original MIT-licensed work. Please keep attribution intact and keep changes focused, respectful, and easy to review.

## Before you open a pull request

Use the repo's standard checks:

```bash
npm run typecheck
npm test
npm run build
```

## Scope and style

- Prefer small, targeted pull requests.
- Carry only the fixes or improvements needed for the change.
- Avoid unrelated refactors in the same pull request.
- Update tests when behavior changes.
- Keep docs and examples aligned when needed.

## Pull request flow

1. Create a branch for your change.
2. Make the smallest change that solves the problem.
3. Run `npm run typecheck`, `npm test`, and `npm run build`.
4. Open a pull request with a clear summary, validation notes, and any tradeoffs.

## Reporting bugs and requesting features

Please use the issue templates so reports include the context needed to reproduce or evaluate a change.

## Questions and conduct

By participating, you agree to follow the [Code of Conduct](./CODE_OF_CONDUCT.md).
